## Import

```ts
import { Spinner } from "areia";
```

## Usage

<Preview
  code={
    'import { ilha } from "ilha";\nimport { Spinner } from "areia";\n\nexport default ilha.render(() => (\n  <Spinner aria-label="Loading" />\n));'

  <Demo2 client:load />

`Button` uses `Spinner` automatically when `loading` is true.

## API Reference

| Prop        | Type                     | Default  | Description             |
| ----------- | ------------------------ | -------- | ----------------------- |
| `size`      | `"sm" \| "base" \| "lg"` | `"base"` | Spinner size.           |
| `class`     | `string`                 | -        | Additional CSS classes. |
| `className` | `string`                 | -        | Alias for `class`.      |
