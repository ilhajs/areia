## API Reference

| Prop          | Type                              | Default     | Description                                                                 |
| ------------- | --------------------------------- | ----------- | --------------------------------------------------------------------------- |
| `icon`        | `unknown`                         | -           | Icon markup rendered before the banner content.                             |
| `title`       | `unknown`                         | -           | Primary heading text for the banner.                                        |
| `description` | `unknown`                         | -           | Secondary description displayed below the title.                            |
| `action`      | `unknown`                         | -           | Action slot rendered at the trailing end of structured banners.             |
| `text`        | `unknown`                         | -           | Simple banner content used when `title` and `description` are not provided. |
| `variant`     | `"default" \| "alert" \| "error"` | `"default"` | Visual style of the banner.                                                 |
| `class`       | `string`                          | -           | Additional CSS classes merged with the generated classes.                   |
| `className`   | `string`                          | -           | Alias for `class`.                                                          |
