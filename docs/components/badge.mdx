Displays a small label for status, categorization, or metadata.

```ts preview twoslash
import ilha, { html } from "ilha";
import { Badge } from "areia";

const Example = ilha.render(
  () => html`
    <div class="flex flex-wrap items-center gap-2">
      ${Badge({ variant: "primary", children: "Primary" })}
      ${Badge({ variant: "secondary", children: "Secondary" })}
      ${Badge({ variant: "error", children: "Error" })}
      ${Badge({ variant: "success", children: "Success" })}
      ${Badge({ variant: "warning", children: "Warning" })}
      ${Badge({ variant: "info", children: "Info" })}
      ${Badge({ variant: "outline", children: "Outline" })}
      ${Badge({ variant: "beta", children: "Beta" })}
    </div>
  `,
);
Example.mount(document.getElementById("root")!);
```

## Import

```ts
import { Badge } from "areia";
```

## Usage

```ts preview
import ilha, { html } from "ilha";
import { Badge } from "areia";

const Example = ilha.render(
  () => html`${Badge({ children: "New" })}`,
);
Example.mount(document.getElementById("root")!);
```

## Examples

### Semantic Variants

Use semantic variants for common status and categorization states.

```ts preview
import ilha, { html } from "ilha";
import { Badge } from "areia";

const Example = ilha.render(
  () => html`
    <div class="flex flex-wrap items-center gap-2">
      ${Badge({ variant: "primary", children: "Primary" })}
      ${Badge({ variant: "secondary", children: "Secondary" })}
      ${Badge({ variant: "error", children: "Error" })}
      ${Badge({ variant: "success", children: "Success" })}
      ${Badge({ variant: "warning", children: "Warning" })}
      ${Badge({ variant: "info", children: "Info" })}
      ${Badge({ variant: "outline", children: "Outline" })}
      ${Badge({ variant: "beta", children: "Beta" })}
    </div>
  `,
);
Example.mount(document.getElementById("root")!);
```

### Other Variants

Use color variants for product-specific labels where semantic badges are not enough to convey the intended meaning or status.

```ts preview
import ilha, { html } from "ilha";
import { Badge } from "areia";

const Example = ilha.render(
  () => html`
    <div class="flex flex-wrap items-center gap-2">
      ${Badge({ variant: "neutral", children: "Neutral" })}
      ${Badge({ variant: "red", children: "Red" })}
      ${Badge({ variant: "orange", children: "Orange" })}
      ${Badge({ variant: "green", children: "Green" })}
      ${Badge({ variant: "teal", children: "Teal" })}
      ${Badge({
        variant: "teal-subtle",
        children: "Teal Subtle",
      })}
      ${Badge({ variant: "blue", children: "Blue" })}
      ${Badge({ variant: "purple", children: "Purple" })}
    </div>
  `,
);
Example.mount(document.getElementById("root")!);
```

### In a Sentence

Badges can be used inline with nearby text to call attention to lightweight metadata.

```ts preview
import ilha, { html } from "ilha";
import { Badge } from "areia";

const Example = ilha.render(
  () => html`
    <p class="flex items-center gap-2 text-areia-default">
      Ilha Islands
      ${Badge({ variant: "success", children: "Stable" })}
    </p>
  `,
);
Example.mount(document.getElementById("root")!);
```

## API Reference

| Prop        | Type                                                                                                                                                                                                            | Default     | Description                                               |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | --------------------------------------------------------- |
| `variant`   | `"primary" \| "secondary" \| "error" \| "warning" \| "success" \| "destructive" \| "info" \| "beta" \| "outline" \| "red" \| "green" \| "neutral" \| "orange" \| "purple" \| "teal" \| "teal-subtle" \| "blue"` | `"primary"` | Color variant of the badge.                               |
| `children`  | `unknown`                                                                                                                                                                                                       | -           | Content rendered inside the badge.                        |
| `class`     | `string`                                                                                                                                                                                                        | -           | Additional CSS classes merged with the generated classes. |
| `className` | `string`                                                                                                                                                                                                        | -           | Alias for `class`.                                        |
