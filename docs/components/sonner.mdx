Sonner provides non-blocking toast notifications using Areia's Ilha component API.
Render Areia's `Toaster` once in your app shell, then call `toast` from [`sonner`](https://sonner.emilkowal.ski/) anywhere in client code.

[Source Code](https://github.com/ilhajs/areia/blob/main/packages/areia/src/components/sonner/index.ts)

## Import

```ts
import { Toaster } from "areia";
import { toast } from "sonner";
```

## Setup

Add the toaster once near the root of your app.

```tsx
import { Toaster } from "areia";

<Toaster position="bottom-right" closeButton theme="system" />;
```

## Usage

```ts
import { toast } from "sonner";

toast.success("Project saved");
toast.error("Something went wrong");
toast.message("Invite sent", {
  description: "Your teammate will receive an email shortly.",
});
```

## Example

```tsx preview twoslash
// @errors: 2322 2686
// @ts-nocheck
// ---cut---
import ilha from "ilha";
import { Button, Toaster } from "areia";
import { toast } from "sonner";

export default ilha
  .on("button@click", () => {
    toast.success("Project saved", {
      description: "Your changes are now live.",
    });
  })
  .render(() => (
    <div class="flex flex-col gap-4">
      <Button variant="primary">Save project</Button>
      <Toaster
        position="bottom-right"
        closeButton
        richColors
        theme="system"
      />
    </div>
  ));
```

## API

### Toaster

```ts
Toaster({
  position: "bottom-right",
  theme: "system",
  closeButton: true,
  duration: 4000,
  visibleToasts: 3,
});
```

### toast

```ts
toast("Default toast");
toast.success("Success");
toast.info("Info");
toast.warning("Warning");
toast.error("Error");
toast.loading("Loading");
toast.dismiss();
```

Use toasts for short-lived, non-blocking feedback. For confirmations or required decisions, use `Dialog` instead.
