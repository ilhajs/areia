Displays modal content over the page.

```tsx preview twoslash
// @errors: 2322 2686 2786
import ilha from "ilha";
import { Button, Dialog } from "areia";

export default ilha.render(() => (

            you are done.
          </Dialog.Description>
        </div>
        <div class="flex justify-end gap-2">
          <Dialog.Close>
            <Button variant="secondary">Cancel</Button>
          </Dialog.Close>
          <Dialog.Close>
            <Button variant="primary">Save</Button>
          </Dialog.Close>
        </div>
      </>
    }
  />
));
```

## Import

```ts
import { Dialog } from "areia";
```

## Usage

Use `Dialog` for an interactive dialog. The component renders the required `dialog`, `dialog-trigger`, `dialog-portal`, `dialog-overlay`, and `dialog-content` slots for `@data-slot/dialog`.

```tsx preview
import ilha from "ilha";
import { Button, Dialog } from "areia";

export default ilha.render(() => (
  <Dialog
    trigger={<Button>Open</Button>}
    contentClass="grid gap-4 p-6"
    content={
      <>
        <Dialog.Title>Dialog title</Dialog.Title>
        <Dialog.Description>
          Helpful supporting text for the dialog.
        </Dialog.Description>
        <Dialog.Close>
          <Button>Close</Button>
        </Dialog.Close>
      </>
    }
  />
));
```

## Examples

### Alert dialog

Use `role: "alertdialog"` for confirmation flows that require explicit acknowledgment. Alert dialogs do not close on outside click by default.

```tsx preview
import ilha from "ilha";
import { Button, Dialog } from "areia";

export default ilha.render(() => (
  <Dialog
    role="alertdialog"
    trigger={
      <Button variant="destructive">Delete project</Button>
    }
    contentClass="grid gap-4 p-6"
    content={
      <>
        <div class="grid gap-2">
          <Dialog.Title>Delete project?</Dialog.Title>
          <Dialog.Description>
            This action cannot be undone. The project and all
            related data will be permanently deleted.
          </Dialog.Description>
        </div>
        <div class="flex justify-end gap-2">
          <Dialog.Close>
            <Button variant="secondary">Cancel</Button>
          </Dialog.Close>
          <Dialog.Close>
            <Button variant="destructive">Delete</Button>
          </Dialog.Close>
        </div>
      </>
    }
  />
));
```

### Sizes

```tsx preview
import ilha from "ilha";
import { Button, Dialog } from "areia";

const sizes = ["sm", "base", "lg", "xl"] as const;

export default ilha.render(() => (
  <div class="flex flex-wrap gap-2">
    {sizes.map((size) => (
      <Dialog
        size={size}
        trigger={<Button variant="secondary">{size}</Button>}
        contentClass="grid gap-4 p-6"
        content={
          <>
            <Dialog.Title>{size} dialog</Dialog.Title>
            <Dialog.Description>
              Dialogs constrain their minimum width by size.
            </Dialog.Description>
            <Dialog.Close>
              <Button>Close</Button>
            </Dialog.Close>
          </>
        }
      />
    ))}
  </div>
));
```

### Close behavior

Configure outside-click, Escape, initial open state, and scroll locking through root options.

```tsx preview
import ilha from "ilha";
import { Button, Dialog } from "areia";

export default ilha.render(() => (
  <Dialog
    closeOnClickOutside={false}
    closeOnEscape
    lockScroll
    trigger={<Button>Open locked dialog</Button>}
    contentClass="grid gap-4 p-6"
    content={
      <>
        <Dialog.Title>Explicit close</Dialog.Title>
        <Dialog.Description>
          Clicking outside this dialog will not close it.
        </Dialog.Description>
        <Dialog.Close>
          <Button>Close</Button>
        </Dialog.Close>
      </>
    }
  />
));
```

### Compound helpers

You can compose slots manually when you need lower-level control. Use `Dialog` at the top so the primitive is mounted.

```tsx preview
import ilha from "ilha";
import { Button, Dialog } from "areia";

export default ilha.render(() => (
  <Dialog
    trigger={<Button>Manual trigger</Button>}
    contentClass="p-6"
    content={
      <div class="grid gap-4">
        <Dialog.Title>Manual composition</Dialog.Title>
        <Dialog.Description>
          Trigger, title, description, and close are slot
          helpers.
        </Dialog.Description>
        <Dialog.Close>
          <Button>Done</Button>
        </Dialog.Close>
      </div>
    }
  />
));
```

## API Reference

### `Dialog`

| Prop                  | Type                             | Default                            | Description                                     |
| --------------------- | -------------------------------- | ---------------------------------- | ----------------------------------------------- |
| `trigger`             | `unknown`                        | —                                  | Custom trigger markup.                          |
| `children`            | `unknown`                        | —                                  | Trigger content when `trigger` is not provided. |
| `content`             | `unknown`                        | —                                  | Dialog panel content.                           |
| `size`                | `"sm" \| "base" \| "lg" \| "xl"` | `"base"`                           | Dialog width.                                   |
| `role`                | `"dialog" \| "alertdialog"`      | `"dialog"`                         | Dialog semantic role.                           |
| `defaultOpen`         | `boolean`                        | `false`                            | Initial open state.                             |
| `closeOnClickOutside` | `boolean`                        | `true` (`false` for alert dialogs) | Close when clicking outside content.            |
| `closeOnEscape`       | `boolean`                        | `true`                             | Close when pressing Escape.                     |
| `lockScroll`          | `boolean`                        | `true`                             | Lock body scroll while open.                    |
| `onOpenChange`        | `(open: boolean) => void`        | —                                  | Called when open state changes.                 |
