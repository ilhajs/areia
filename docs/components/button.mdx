Displays a button or a component that looks like a button.

```ts preview twoslash
import ilha, { html } from "ilha";
import { Plus } from "lucide";
import { Button, Icon } from "areia";

const plusIcon = Icon({ icon: Plus });

const Example = ilha.render(
  () => html`
    <div class="flex flex-wrap items-center gap-2">
      ${Button({ variant: "secondary", children: "Button" })}
      ${Button({
        variant: "secondary",
        shape: "square",
        icon: plusIcon,
        "aria-label": "Add",
      })}
    </div>
  `,
);
Example.mount(document.getElementById("root")!);
```

## Import

```ts
import { Button } from "areia";
```

## Usage

```ts preview
import ilha, { html } from "ilha";
import { Button } from "areia";

const Example = ilha.render(
  () =>
    html`${Button({
      variant: "secondary",
      children: "Click me",
    })}`,
);
Example.mount(document.getElementById("root")!);
```

### Icon Only

For icon-only buttons, use `shape="square"` or `shape="circle"` with the `icon` prop. Always include `aria-label` for accessibility — without visible text, screen readers need the label to convey the button’s purpose.

```ts preview
import ilha, { html } from "ilha";
import { Plus } from "lucide";
import { Button, Icon } from "areia";

const plusIcon = Icon({ icon: Plus });

const Example = ilha.render(
  () => html`
    <div class="flex flex-wrap items-center gap-3">
      ${Button({
        variant: "secondary",
        shape: "square",
        icon: plusIcon,
        "aria-label": "Add item",
      })}
      ${Button({
        variant: "secondary",
        shape: "circle",
        icon: plusIcon,
        "aria-label": "Add item",
      })}
    </div>
  `,
);
Example.mount(document.getElementById("root")!);
```

### Title

Use the native `title` attribute when additional context helps the user understand the action.

```ts preview
import ilha, { html } from "ilha";
import { Plus } from "lucide";
import { Button, Icon } from "areia";

const plusIcon = Icon({ icon: Plus });

const Example = ilha.render(
  () => html`
    <div class="flex flex-wrap items-center gap-3">
      ${Button({
        variant: "secondary",
        title: "Create a new Ilha app",
        children: "Create Ilha app",
      })}
      ${Button({
        variant: "secondary",
        shape: "square",
        icon: plusIcon,
        "aria-label": "Add item",
        title: "Add item",
      })}
    </div>
  `,
);
Example.mount(document.getElementById("root")!);
```

### Link as Button

Use `LinkButton` when the interaction should navigate somewhere but still look like a button. Use `Button` for in-place actions like submitting, opening, or toggling UI.

```ts preview
import ilha, { html } from "ilha";
import { ExternalLink } from "lucide";
import { LinkButton, Icon } from "areia";

const externalIcon = Icon({ icon: ExternalLink });

const Example = ilha.render(
  () => html`
    <div class="flex flex-wrap items-center gap-3">
      ${LinkButton({
        href: "/components/link",
        variant: "secondary",
        children: "Read Link docs",
      })}
      ${LinkButton({
        href: "https://ilha.build/",
        variant: "ghost",
        icon: externalIcon,
        external: true,
        children: "Ilha Docs",
      })}
    </div>
  `,
);
Example.mount(document.getElementById("root")!);
```

## API Reference

| Prop        | Type                                                                                           | Default       | Description                                               |
| ----------- | ---------------------------------------------------------------------------------------------- | ------------- | --------------------------------------------------------- |
| `shape`     | `"base" \| "square" \| "circle"`                                                               | `"base"`      | Controls the button shape.                                |
| `size`      | `"xs" \| "sm" \| "base" \| "lg"`                                                               | `"base"`      | Controls button height, padding, gap, and text size.      |
| `variant`   | `"primary" \| "secondary" \| "ghost" \| "destructive" \| "secondary-destructive" \| "outline"` | `"secondary"` | Controls the visual style.                                |
| `children`  | `unknown`                                                                                      | -             | Content rendered inside the button.                       |
| `class`     | `string`                                                                                       | -             | Additional CSS classes merged with the generated classes. |
| `className` | `string`                                                                                       | -             | Alias for `class`.                                        |
| `icon`      | `unknown`                                                                                      | -             | Markup rendered before the label.                         |
| `loading`   | `boolean`                                                                                      | -             | Shows a loading spinner and disables interaction.         |
| `title`     | `string`                                                                                       | -             | Native tooltip text.                                      |
| `disabled`  | `boolean`                                                                                      | -             | Disables the button.                                      |
| `name`      | `string`                                                                                       | -             | Native button name attribute.                             |
| `type`      | `"submit" \| "reset" \| "button"`                                                              | `"button"`    | Native button type attribute.                             |
| `value`     | `string \| string[] \| number`                                                                 | -             | Native button value attribute.                            |
