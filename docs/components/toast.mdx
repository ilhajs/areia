---
title: Toast
description: Toast notifications for short-lived feedback.
---

Areia does not ship a dedicated Toast component yet. Use [`vanilla-sonner`](https://github.com/devwaseem/vanilla-sonner) meanwhile.

## Installation

```sh
npm install vanilla-sonner
```

Import the package and stylesheet once in your application entry point.

```ts
import { toast } from "vanilla-sonner";
import "vanilla-sonner/style.css";
```

## Setup

Add the toaster container once in your app shell.

```html
<ol
  id="sonner-toast-container"
  position="bottom-right"
  max-toasts="3"
  duration="4000"
  close-button="true"
  rich-colors="true"
  theme="system"
></ol>
```

## Usage

```ts
import { toast } from "vanilla-sonner";

toast.success("Project saved");
toast.error("Something went wrong");
```

## Example

```ts preview twoslash
// @ts-nocheck
// ---cut---
import ilha, { html } from "ilha";
import { toast } from "vanilla-sonner";
import "vanilla-sonner/style.css";
import { Button } from "areia";

const Example = ilha
  .on("button@click", () => {
    toast.success("Project saved");
  })
  .render(
    () => html`
      <div class="flex flex-col gap-4">
        ${Button({ label: "Save project", variant: "primary" })}
        <ol
          id="sonner-toast-container"
          position="bottom-right"
          max-toasts="3"
          duration="4000"
          close-button="true"
          rich-colors="true"
          theme="system"
        ></ol>
      </div>
    `,
  );
// ---cut-after---
Example.mount(document.getElementById("root")!);
```

Use toasts for short-lived, non-blocking feedback. For confirmations or required decisions, use `Dialog` instead.
